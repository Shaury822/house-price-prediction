# Model Evaluation Report

## House Price Prediction System

### Model Used

Random Forest Regression

### Evaluation Metrics

| Metric | Score |
|---|---:|
| MAE | 15.77 |
| RMSE | 19.67 |
| R² Score | 0.9716 |

### Result

The Random Forest Regression model achieved an R² score of approximately 97.16% on the test dataset.

This indicates that the model explains approximately 97.16% of the variation in house prices in the test data.

The model was also tested using a new house input and successfully generated a predicted house price of approximately 164.44 Lakh for the sample input.

### Conclusion

The trained Random Forest Regression model provides strong predictive performance for the given house price dataset and can be used as the prediction engine for the Streamlit application.
